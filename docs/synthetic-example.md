# Synthetic Before / After Evidence

All names, identifiers, country labels, dates and addresses in this fixture are synthetic. `.invalid` addresses are demonstration placeholders. No customer records are used.

- [Before CSV](examples/before.synthetic.csv)
- [After CSV](examples/after.synthetic.csv), generated by the unchanged cleaner

## Reproduce

From the repository root after installing declared dependencies:

```bash
PYTHONPATH=src python -c "from csv_cleaner_validator.cleaner import clean_and_validate_csv; print(clean_and_validate_csv('docs/examples/before.synthetic.csv', 'output/after.synthetic.csv', ['customer_id','name','email','country','signup_date']))"
```

On Windows, set `PYTHONPATH` to `src` before the Python command. Compare `output/after.synthetic.csv` with the committed after fixture. Keep the input and output paths distinct.

Generated with Pandas 2.2.3 using the unchanged cleaner from commit `e6b40807d7176330d6790e2ae0b9501e93529a7b`.

| Evidence | Observed result |
|---|---|
| Original parsed rows | 4 |
| Rows after fully empty removal | 4 (this fixture contains no empty row) |
| Duplicates removed after normalization | 1 |
| Final rows | 3 |
| Remaining missing values | email: 1 |
| Heading/text normalization | `Customer ID` becomes `customer_id`; surrounding spaces in `Demo One` removed |
| Deduplication | First two raw rows differ in name whitespace; normalize to one row |
| Identifier typing | `001`, `002`, `003` become `1`, `2`, `3`; leading zeros are lost through input type inference |
| Semantic validation | `not-a-date` and `not-an-email` remain in output |

Required headings are present despite missing and invalid cell values. Missing values are counted after deduplication, only for affected columns; no missing-value imputation occurs. This fixture does not cover every behavior. The original demo and existing tests also exercise fully empty-row removal.

No identifier-preservation claim, API service, or integration deployment is implied. See [design decisions](design-decisions.md) for source-preservation and normalization limits.
